# SenchScroll → Google Play

## 0. Риски — прочитай сначала

- **Спецвозможности.** Google Play запрещает использовать API специальных возможностей, чтобы приложение само планировало и совершало действия. Разрешена обычная автоматизация по заданным правилам вида «сделай X, когда случится Y». SenchScroll работает именно так: свайп раз в N секунд, открыть и закрыть комменты. Нейронка пишет только текст и ничем не управляет. Это главный аргумент в декларации, но решение принимает модератор, и отказ вполне возможен.
- **TikTok.** Правила TikTok запрещают автоматический доступ к сервису. Google может отклонить приложение, если сочтёт, что оно мешает работе другого приложения. В описании не используй логотип и фирменный стиль TikTok.
- **Если откажут**, раздавай версию APK файлом, как сейчас.

## 3. Тексты для страницы приложения

**Название (до 30 символов):** SenchScroll — ИИ-журнал ленты

**Краткое описание (до 80 символов):** Нейронка листает видеоленту за тебя и пишет журнал: о чём видео и что в комментах

**Полное описание:**
SenchScroll листает ленту коротких видео вместо тебя и пишет понятный журнал.

Нажми «Запустить», положи телефон, и приложение будет само листать ленту, открывать и читать комментарии. Нейронка по каждому видео напишет:
• о чём видео, своими словами;
• что в целом думают люди в комментариях;
• категорию, настроение и «имба-метр» от 1 до 10.

В конце сессии нейронка подводит итог ленты: темы, топ-3 видео и общий вайб.

Нейронку выбираешь сам: Gemini, Groq, Mistral, OpenRouter (бесплатные ключи), Grok или Claude (платные ключи). Ключ хранится только на телефоне.

Приложение ничего не лайкает, не пишет и не подписывается. Журнал хранится только на телефоне.

Используется API специальных возможностей Android: только чтобы во время запущенной тобой сессии делать свайпы, открывать комментарии и читать текст на экране видео. Подробнее — в окне согласия в приложении.

*Не связано с TikTok и ByteDance.*

**Категория:** Инструменты (или «Развлечения»).

## 4. Декларация спецвозможностей (Play Console → Содержание приложения)

- **Является ли приложение инструментом для людей с ограниченными возможностями?** Нет.
- **Зачем нужен API:** Функциональность приложения.
- **Описание (по-английски, модераторы читают так быстрее):**

> SenchScroll uses the AccessibilityService API only during a session that the user explicitly starts with the "Start" button. During the session it performs simple rule-based actions: a vertical swipe after a fixed user-chosen time, opening and closing the comments panel. It reads visible on-screen text (video caption, author name, comments) and, if enabled, takes screenshots of the video to generate a text summary with an AI service that the user chooses and configures with their own API key. The AI only writes text summaries and never decides or initiates any actions. The app never likes, comments, follows or sends messages. Data is shown to the user in a local journal and is not sent to the developer. A prominent in-app disclosure with explicit consent is shown before the user is sent to the accessibility settings.

## 5. Безопасность данных (Data safety)

- **Собирает или передаёт данные:** Да — **передаёт**: «Контент приложения → Прочий пользовательский контент» (текст с экрана и кадры), «Фото и видео» (кадры).
- **Цель:** Функциональность приложения.
- **Получатель:** выбранный пользователем ИИ-сервис (Google Gemini, Groq, Mistral, OpenRouter, xAI или Anthropic).
- **Данные шифруются при передаче:** Да (HTTPS).
- **Пользователь может удалить данные:** Да («Очистить журнал», «Удалить сессию»).
- **Сбор необязательный:** Нет, это основная функция. Но всё работает только после явного запуска.
