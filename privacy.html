SenchScroll — политика конфиденциальности

Действует с 25 ноября 2026 г.

Что делает приложение

SenchScroll по команде пользователя листает ленту коротких видео, читает текст на экране и комментарии и с помощью выбранного пользователем ИИ-сервиса пишет журнал: о чём были видео и что в них обсуждают.

API специальных возможностей

Приложение использует API специальных возможностей Android (AccessibilityService) только во время сессии, которую пользователь сам запустил кнопкой «Запустить». Через этот API приложение:

  • делает свайпы и открывает/закрывает панель комментариев;
  • читает видимый текст на экране видеоприложения (имя автора, подпись, хэштеги, музыку, комментарии);
  • если пользователь включил «Нейронка смотрит кадры», делает снимки экрана видео.

Приложение не читает другие приложения, ничего не лайкает, не пишет, не подписывается и не отправляет сообщения.

Какие данные и куда передаются

  • Текст с экрана, текст комментариев и кадры видео передаются по HTTPS только в ИИ-сервис, который пользователь выбрал в настройках (Google Gemini, Groq, Mistral, OpenRouter, xAI или Anthropic), чтобы получить текстовое описание. На эти данные распространяется политика конфиденциальности выбранного сервиса.
  • API-ключ ИИ-сервиса хранится только на устройстве.
  • Журнал (описания, превью кадров) хранится только на устройстве. Его можно удалить в приложении («Удалить сессию», «Очистить журнал») или удалив приложение.
  • Отчёт об ошибках (модель телефона, версии Android и приложений, место ошибки) хранится только на устройстве и отправляется разработчику, только если пользователь сам нажмёт «Поделиться отчётом».

Разработчик не собирает и не хранит данные пользователей, не использует аналитику и рекламу.

Дети

Приложение не предназначено для детей младше 16 лет.
