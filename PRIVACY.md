# SenchScroll — политика конфиденциальности

*Действует с 25 ноября 2026 г.*

## Что делает приложение

SenchScroll по команде пользователя листает ленту коротких видео. Приложение читает текст на экране и комментарии, а ИИ-сервис, который выбрал пользователь, пишет по ним журнал: о чём были видео и что в них обсуждают.

## API специальных возможностей

Приложение использует API специальных возможностей Android (AccessibilityService). Это происходит только во время сессии, которую пользователь сам запустил кнопкой «Запустить». Через этот API приложение:

- делает свайпы, открывает и закрывает панель комментариев;
- читает видимый текст на экране видеоприложения: имя автора, подпись, хэштеги, музыку, комментарии;
- делает снимки экрана видео, если пользователь включил «Нейронка смотрит кадры».

Приложение не читает другие приложения. Оно ничего не лайкает, не пишет, не подписывается и не отправляет сообщения.

## Какие данные и куда передаются

- **Текст с экрана, текст комментариев и кадры видео** передаются по HTTPS только в ИИ-сервис, выбранный пользователем в настройках: Google Gemini, Groq, Mistral, OpenRouter, xAI или Anthropic. Сервис получает их, чтобы написать текстовое описание. На эти данные распространяется политика конфиденциальности выбранного сервиса.
- **API-ключ ИИ-сервиса** хранится только на устройстве.
- **Журнал** (описания и превью кадров) хранится только на устройстве. Его можно удалить в приложении кнопками «Удалить сессию» и «Очистить журнал» или вместе с приложением.
- **Отчёт об ошибках** хранится только на устройстве. В нём модель телефона, версии Android и приложений и место ошибки. Разработчик получает его, только если пользователь сам нажмёт «Поделиться отчётом».

Разработчик не собирает и не хранит данные пользователей. В приложении нет аналитики и рекламы.
